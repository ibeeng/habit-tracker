rootine — privacy policy

terakhir diperbarui: 24 September 2026

Kebijakan Privasi ini menjelaskan bagaimana Rootine ("kami") memproses informasi saat kamu menggunakan aplikasi habit tracker kami yang tersedia di https://ibeeng.github.io/habit-tracker/ ("Layanan").

Ringkasan singkat:
  • Data habit disimpan di browser kamu sendiri (localStorage) — bukan di server kami.
  • Login pakai Google hanya untuk verifikasi identitas — kami tidak menyimpan password.
  • Kami tidak menjual data kamu ke pihak mana pun.
  • Sync (Telegram) bersifat opsional dan hanya aktif jika kamu mengaktifkannya.

1. Informasi yang kami kumpulkan

a. Saat login dengan Google

  • Nama tampilan, alamat email, dan URL foto profil (jika tersedia)
  • Identifier akun Google (sub) — untuk membedakan akun

Kami tidak menerima atau menyimpan password Google kamu.

b. Data habit (lokal)

  • Nama habit, jadwal, progres, streak, XP, shield, preferensi tema
  • Disimpan di localStorage browser pada perangkat kamu
  • Tidak dikirim ke server Rootine

c. Jika kamu mengaktifkan sync (opsional)

  • Telegram: jika kamu menghubungkan bot Telegram milikmu sendiri, data habit dikirim sebagai file JSON ke chat bot tersebut. Token bot disimpan lokal di browser kamu.

2. Cara kami menggunakan informasi

  • Menampilkan dan mengelola habit kamu
  • Menjaga sesi login tetap aktif
  • Menyinkronkan data antar perangkat — hanya jika kamu aktifkan fitur sync

3. Penyimpanan & keamanan

  • Data habit utama: localStorage browser (perangkat)
  • Sesi login: localStorage browser (token kedaluwarsa mengikuti token Google)
  • Data sync: di penyimpanan milik kamu sendiri (Telegram), bukan server kami
  • Kami tidak mengoperasikan basis data server yang menyimpan data habit kamu

4. Berbagi data

Kami tidak menjual, menyewakan, atau membagikan data pribadi kamu kepada pengiklan, pihak ketiga untuk tujuan pemasaran, atau pihak lain — kecuali:

  • Kamu secara eksplisit mengaktifkan sync ke Telegram
  • Diwajibkan oleh hukum yang berlaku

5. Layanan pihak ketiga

  • Google Sign-In (Google Identity Services) — untuk login. Kebijakan privasi Google: policies.google.com/privacy
  • Telegram Bot API — hanya jika kamu menghubungkan bot Telegram
  • GitHub Pages — hosting statis aplikasi ini

6. Hak kamu

  • Menghapus data habit: menu ⋮ → reset data di aplikasi
  • Menghapus backup JSON: hapus file dari chat Telegram kamu
  • Memutus sync: menu sync → disconnect
  • Menarik izin Google: myaccount.google.com/permissions
  • Menghapus akun / sesi: tombol sign out

7. Data anak

Layanan ini tidak ditujukan untuk anak di bawah 13 tahun. Kami tidak dengan sengaja mengumpulkan data anak.

8. Perubahan kebijakan ini

Kami dapat memperbarui Kebijakan Privasi dari waktu ke waktu. Tanggal "terakhir diperbarui" akan selalu menampilkan versi terbaru. Perubahan materiil akan ditampilkan di aplikasi.

9. Kontak

Pertanyaan soal privasi? Buka issue di github.com/ibeeng/habit-tracker/issues atau hubungi kami melalui GitHub (@ibeeng).
