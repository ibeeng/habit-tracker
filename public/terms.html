Syarat & Ketentuan ini ("Syarat") mengatur penggunaan kamu atas aplikasi Rootine ("Layanan") yang tersedia di https://ibeeng.github.io/habit-tracker/.

Dengan mengakses atau menggunakan Rootine, kamu dianggap telah membaca dan menyetujui Syarat ini. Jika tidak setuju, mohon jangan gunakan Layanan.

1. Deskripsi Layanan

Rootine adalah aplikasi web (PWA) untuk melacak habit / kebiasaan harian — termasuk streak, statistik, shield, dan gamifikasi (XP, level, achievement). Data utama disimpan secara lokal di browser kamu. Fitur login Google dan sync (Google Drive / Telegram) bersifat opsional.

2. Akun & Login

  • Login dilakukan menggunakan akun Google kamu (Google Sign-In).
  • Kamu bertanggung jawab menjaga keamanan akun Google kamu sendiri.
  • Kami tidak menyimpan password — kami hanya menerima token identitas dari Google.
  • Kamu harus berusia minimal 13 tahun (atau sesuai usia minimum di yurisdiksimu) untuk menggunakan Layanan.

3. Data & Tanggung Jawab Kamu

  • Data habit tersimpan di localStorage browser kamu. Menghapus data browser, menggunakan perangkat/browser lain, atau mode privat dapat menghilangkan data lokal.
  • Kamu bertanggung jawab atas backup data kamu sendiri (fitur export/import JSON, dan sync opsional ke Google Drive / Telegram).
  • Jika kamu mengaktifkan sync ke Telegram dengan bot milikmu sendiri, token bot disimpan di browser kamu — jangan bagikan token tersebut ke orang lain.
  • Kami tidak bertanggung jawab atas kehilangan data yang terjadi akibat kelalaian backup, penghapusan browser, atau perubahan pada penyimpanan sync milikmu.

4. Penggunaan yang dilarang

Kamu tidak boleh:

  • Menggunakan Layanan untuk tujuan ilegal atau melanggar hukum yang berlaku
  • Mencoba mengakses, memanipulasi, atau merusak Layanan / infrastruktur kami
  • Menyalahgunakan fitur login atau sync (mis. mengganggu API Google / Telegram melalui aplikasi ini)
  • Melakukan scraping, scraping balik, atau penggunaan otomatis yang merugikan
  • Menggunakan Layanan untuk menyebarkan konten yang melanggar hak pihak ketiga
